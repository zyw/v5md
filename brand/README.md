# v5md Brand Kit

方向：**Peek**（光标显形 `#`）  
主色：Ink Teal `#0F766E` · Ink `#0B1220` · Mist `#F0FDFA`

> **清晰度**：线上展示请优先用 `.svg`（矢量，任意缩放都清晰）。  
> PNG 已按 **2×** 导出，适合 Retina；若仍觉得糊，说明在用 PNG 被放大了，请改回 SVG 或再要更高分辨率。
