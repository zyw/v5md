# v5md — Logo Guidelines

## 1. Logo
- **Idea**：光标落下，`#` 才显形——「标记按需显形」。
- **Versions**：horizontal · stacked · symbol · wordmark
- **Files**：`brand/logo/` · Web 套件：`brand/logo/web/`

## 2. Clear space
以符号内 **caret 宽度** 为 1×，四周至少留白 1×。

## 3. Minimum size
| Version | Screen | Print |
|---|---|---|
| Horizontal | 120 px 宽 | 28 mm 宽 |
| Symbol | 16 px（用 `v5md-symbol-small` / `web/favicon*`） | 6 mm |

## 4. Colour
| Name | HEX | 用途 |
|---|---|---|
| Ink Teal | `#0F766E` | 主色 / app 底 |
| Ink | `#0B1220` | 字标 |
| Mist | `#F0FDFA` | 浅底 |
| White | `#FFFFFF` | 反白 |

**可用组合**：彩色/黑 on white · 白 on Ink Teal · 白 on Ink。深色界面优先 `v5md-symbol-reversed.svg`。

## 5. Typography
- 字标由 **Helvetica Neue Bold** 描边为路径，不要重打 `v5md`。
- UI：`Helvetica Neue` / system-ui；代码：ui-monospace。

## 6. Don'ts
不要拉伸、改色、旋转、加阴影描边渐变、拆 lockup、在杂乱背景上硬叠。
