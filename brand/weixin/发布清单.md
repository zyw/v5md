# 公众号发布清单

发布前逐项打勾，全部通过再点「群发」。

## 一、内容

- [ ] 标题从 [`v5md-公众号文案.md`](v5md-公众号文案.md) 的 5 个备选里选定，总长 ≤ 32 字（现有备选 24 / 24 / 32 / 13 / 35 字；3、5 号偏长，选它们时确认截断后仍通顺）。信息流大约只露两行，**前 20 字要能独立看懂**。
- [ ] 摘要 ≤ 120 字，没有从正文里直接截取半句话。
- [ ] 正文只复制了 `<!-- 正文开始 -->` 之后的部分，没有把「发布信息」带进去。
- [ ] 文中的 GitHub（<https://github.com/zyw/v5md>）、Demo（<https://v5md-demo.v5ai.xin>）地址逐字核对过。
- [ ] 文中所有功能描述都能在 [`README.md`](../../README.md) 或 [`CHANGELOG.md`](../../CHANGELOG.md) 找到依据，没有 star 数、下载量、性能对比这类没来源的数字。
- [ ] 版本号写的是 `0.0.4`，包数量是 9 个。

## 二、封面

- [ ] 主封面：[`images/cover-235x1-dark@2x.png`](images/cover-235x1-dark@2x.png)（1800×766，2.35:1）。
- [ ] 分享封面：[`images/cover-1x1-dark@2x.png`](images/cover-1x1-dark@2x.png)（766×766，1:1）。
- [ ] 在公众号后台的封面预览里看过：标题没有被裁切，缩略图尺寸下仍能读清主标题。
- [ ] 备选浅色封面 [`images/cover-235x1-light@2x.png`](images/cover-235x1-light@2x.png) 已确认不用或已替换。

## 三、排版

- [ ] 正文配图按「配图建议」从 [`screenshots/`](screenshots/) 补齐（6 张 1080px 实拍图，已备好），公众号会把宽图缩到正文宽度。
- [ ] 插完图把正文里 4 处 `> 配图建议（发布前删除本行）：…` 删掉，群发正文只留图片和图注。
- [ ] 代码片段改成等宽字体段落或截图。公众号编辑器不做语法高亮，直接贴围栏代码块会变成纯文本。
- [ ] 每个小节之间留空行，段落不超过 3 行，手机上不要出现大段文字墙。
- [ ] 重点句加粗控制在 15 处以内（`**GitHub**`、`**Demo**` 这类列表标签不计），否则重点失效。
- [ ] 图片都有替代文字（无障碍 + 加载失败时的兜底）。

## 四、链接与转化

- [ ] 公众号正文外链默认不可点击：Demo 放「阅读原文」，GitHub 放关键词自动回复或公众号菜单（「阅读原文」只能填一个链接）。
- [ ] 「阅读原文」链接填 <https://v5md-demo.v5ai.xin>（Demo 比仓库更容易让人立刻上手）。
- [ ] 自动回复关键词（如「v5md」）里放了仓库和 Demo 地址。
- [ ] 公众号菜单里加「v5md Demo」入口。

## 五、发之前

- [ ] 先发「预览」到自己的微信，在手机上完整读一遍（重点看代码块、表格、封面裁切）。
- [ ] 用另一台安卓手机再看一遍，确认字体和行距没有崩。
- [ ] 原创声明、作者、合集/话题都填好。
- [ ] 定时或立即群发的时间避开深夜；技术号工作日 8:00-9:00 或 12:00-13:00 打开率通常更高。
